# PLP2 - OOP Activity 1: Airline Ticket Booking System


## About the Project
This is our group submission for the Object-Oriented Programming (OOP) activity. We built a command-line airline booking system in Python that uses inheritance to handle different passenger classes (Economy, Business, and First Class). 


## Group Members & Contributions
We divided the work equally to make sure everyone understood the OOP concepts:


  **Anyieth Maker Thiong But** - Base Logic & Economy: Wrote the main Passenger base class and the Economy child class. Handled the initial setup of the super().__init__() to make sure the inheritance works correctly.
  **Kim Berly Marilyse Ndayiragije** - Business & First Class: Wrote the Business class (overriding the default weight to 100kg) and the First Class class (handling the suite number and the True/False chauffeur service).
  **Arthur Nziza** - Input, Error Handling & Testing: Wrote the main() function to handle the terminal workflow. Added all the error handling (checking for empty strings and invalid menu choices) and tested the program to make sure it doesn't crash.
## How to Run the Program
1. Make sure you are in the project folder in your terminal.
2. Run the Python script:
   
bash
   python3 booking_system.py
