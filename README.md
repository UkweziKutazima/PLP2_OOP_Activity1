# PLP2 - OOP Activity 1: Airline Ticket Booking System


## About the Project
This project is a command-line airline booking system built in Python. It uses Object-Oriented Programming (OOP) and inheritance to handle different passenger classes (Economy, Business, and First Class). 


## Work Done
  Wrote the main Passenger base class and the Economy, Business, and First Class child classes.
  Implemented super().__init__() to correctly inherit attributes from the parent class.
  Overrode the get_weight_allowance() method in the Business class to return 100kg.
  Added error handling to check for empty inputs and invalid menu choices to prevent the program from crashing.
## How to Run the Program
1. Make sure you are in the project folder in your terminal.
2. Run the Python script:
   
bash
   python3 PLP2_OOP_Activity1.py
